# Yana Invitation

Мобильная история-приглашение, выполненная как приложение.

## Структура

- `index.html` — точка входа.
- `css/variables.css` — тема, переменные и базовые стили.
- `css/animations.css` — ключевые анимации для экрана и кнопок.
- `css/style.css` — основной макет и стили приложения.
- `css/mobile.css` — мобильные уточнения, safe area и компоновка для узких экранов.
- `js/pages.js` — содержимое экранов и структура истории.
- `js/app.js` — логика навигации, перелистывания и прогресса.
- `js/animations.js` — вспомогательные анимации для нажатий кнопок.
- `js/api.js` — заглушка для будущей отправки ответов.
- `assets/` — папки для гифок, иконок и изображений.

## Запуск

Открой `index.html` в браузере.

## Особенности

- Экран занимает весь viewport: `100dvh`.
- Анимация перелистывания экрана: движение влево.
- Верхний прогресс с плавным заполнением.
- Первый экран показывает кнопку `Начать →`.
- Много экранов, как в приложении, чтобы не создавать длинную страницу.
- Поддержка Safe Area для iPhone.
